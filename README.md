Из експорта ПРОМ берем столбцы именно в таком порядке

1 - удаляем все товары Наявність = 0

2 - копируем столбцы на НОВЫЙ лист в правильоном порядке 
          *** картинка  ***  группа  ***   код   ***    наименование   ***    способ упаковки    ****   цена
          
3 - берем цены из 1С правильные

4 - Делаем нужную сортировку (по коду / по имени / по группе)  -  дальше изменить нельзя  -  плывут строки

5 - Формируем как таблицу, чтобы разукрасились строки

6 - Копируем кроме строки с заголовками в файл ПРОМ

7 - Запускаем PY

8 - Добавлем шокеры в конец файла, меняем шрифт, дату

9 - запускаем скрипт Visual Basic 
          ALT/F11 -  запустить редактор  / вставить код из файла  VisualBasic.txt
          ALT/F8  -  выполнить скрипт
